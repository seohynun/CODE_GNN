# 노드별 피처 정리 (최종 모델: CARE-HAN + CatBoost Hybrid)

> ★ = 파생변수 / 원본 YelpZip 컬럼: `text`, `user_id`, `prod_id`, `date`, `rating`, `tag`, `label`

---

## 리뷰 노드 (78차원 = 수동 피처 14개 + TF-IDF SVD 64차원)

| 피처명 | 피처 설명 | 파생변수 여부 |
|--------|-----------|:---:|
| `rating` | 별점 (1~5) | - |
| `weekday` | 리뷰 작성 요일 (`date.dt.weekday`) | ★ |
| `month` | 리뷰 작성 월 (`date.dt.month`) | ★ |
| `rating_deviation` | 해당 식당 평균 별점 대비 편차 | ★ |
| `is_cold_start` | 유저 전체 리뷰 수 == 1이면 1 | ★ |
| `is_single_review` | 해당 식당에 작성한 리뷰 수 == 1이면 1 | ★ |
| `rpr_suspicion` | `abs(rating_deviation)` (장기 충성 유저는 0으로 보정) | ★ |
| `text_len` | 텍스트 문자 수 | ★ |
| `word_count` | 텍스트 단어 수 | ★ |
| `digit_ratio` | 숫자 문자 비율 | ★ |
| `menu_mentions` | 메뉴 관련 키워드 등장 횟수 | ★ |
| `special_ratio` | 특수문자 비율 | ★ |
| `ttr` | Type-Token Ratio (고유단어 수 / 전체단어 수) | ★ |
| `sentiment` | 감성 분석 점수 (VADER/TextBlob) | ★ |
| TF-IDF SVD 1~64 | TF-IDF(5,000 features, bigram) → TruncatedSVD(64차원) 텍스트 임베딩 | ★ |

---

## 유저 노드 (12차원)

| 피처명 | 피처 설명 | 파생변수 여부 |
|--------|-----------|:---:|
| `user_review_count` | 유저의 총 리뷰 작성 수 | ★ |
| `user_fraud_ratio` | 유저 리뷰 중 사기 비율 (Train 기준) | ★ |
| `user_avg_rating` | 유저 평균 별점 | ★ |
| `user_rating_std` | 유저 별점 표준편차 | ★ |
| `activity_span` | 첫 리뷰~마지막 리뷰 사이 일수 | ★ |
| `interval_mean` | 연속 리뷰 간 평균 간격 (일) | ★ |
| `interval_std` | 연속 리뷰 간 간격 표준편차 (일) | ★ |
| `prod_diversity` | 리뷰를 남긴 식당 종류 수 | ★ |
| `user_burst_max7d` | 7일 이내 최대 리뷰 작성 수 (버스트 탐지) | ★ |
| `user_burst_ratio` | 전체 리뷰 중 버스트 기간 리뷰 비율 | ★ |
| `norm_rating_entropy` | 유저 별점 분포의 정규화 엔트로피 | ★ |
| `trust_score` | `activity_span/365 × 0.5 + user_review_count/10 × 0.5` | ★ |

---

## 식당 노드 (6차원)

| 피처명 | 피처 설명 | 파생변수 여부 |
|--------|-----------|:---:|
| `prod_avg_rating` | 식당의 평균 별점 | ★ |
| `prod_rating_std` | 식당 별점 표준편차 | ★ |
| `prod_review_count` | 식당 총 리뷰 수 | ★ |
| `prod_fraud_ratio` | 식당 리뷰 중 사기 비율 (Train 기준) | ★ |
| `prod_burst_user_ratio` | 식당 리뷰 작성자 중 버스트 유저(7일 내 3건↑) 비율 | ★ |
| `is_cold_start_prod` | Train 기준 리뷰 수 < 10이면 1 | ★ |
