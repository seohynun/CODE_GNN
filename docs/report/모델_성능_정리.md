```

↓ +이종 그래프 / Trust-Aware 게이트

CARE-HAN GNN     PR-AUC 0.8221  →  이종 노드 활용 (구조 신호 강화)

↓ +CatBoost 앙상블 (행동 신호 결합)

CARE-HAN+CatBoost PR-AUC 0.9279  ✅ 최종

```
